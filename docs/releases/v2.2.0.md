# Vicu 2.2.0 for Android and iOS

Vicu 2.2.0 makes your settings follow you: the Inbox and the order of your tasks are now the same on every phone, iPhone, iPad and the desktop app. It also makes the data Vicu keeps on your Vikunja server for itself safer, above all in shared projects. Update the desktop app to 2.2.0 at the same time.

### Your Inbox and task order sync

- **The Inbox project is the same on every device.** The first device you update offers its Inbox to the others; a device whose Inbox was different switches to it and tells you so. Choosing another Inbox (Settings, Projects) changes it everywhere. A new device suggests your Inbox during setup.
- **Sort the tasks of a project your way**, with thanks to [@Pegoku](https://github.com/Pegoku): Due date then manual (the default), Due date then priority, Manual, Priority, Title, Newest first or Oldest first. Pick an order for every project in Settings, Projects, Display, or for one project with Sort tasks in its menu (the Inbox has a sort button). A project without its own order follows its parent's. Project and Inbox widgets follow the same order. The order syncs with your other devices and the desktop app.
- In Manual order you can drag every task; in the default order the undated ones; in the sorted orders none.
- The project widget used to list by position and now lists dated tasks first, like the project screen.

### Safer hidden data

Vikunja has no place for an app's own data, so Vicu keeps custom lists, routines and now your settings in tasks it hides.

- **Shared projects no longer mix people's data.** Before, if your Inbox (or another project holding Vicu's hidden tasks) was shared, the other person's Vicu took your custom lists and routines as its own. Now each person's Vicu uses only the hidden tasks they created. Lists or routines that were already mixed cannot be told apart afterwards: delete the ones that are not yours from Custom Lists or Routines.
- Hidden tasks reopened or edited in Vikunja's web app keep working and are hidden again.
- Hidden data a newer version of Vicu wrote is kept and never overwritten; a routine saved by a newer version says so instead of asking for repair.
- Deleted custom lists older than 90 days are cleaned up, so the phone and the desktop app no longer rewrite your custom lists on every sync, and a second copy of your custom lists left by two devices is removed.
- A version older than 2.2.0 shows the new settings task as one done task in the Logbook and search until it updates.

### Fixes

- Discard unsynced changes (Settings, General, Clear cache) now also discards custom-list and settings changes that had not reached the server.
- Signing in to another account no longer keeps parts of the previous sign-in.

### iPhone and iPad

- An iPhone or iPad set up from another device's backup no longer signs out the original device's backup sign-in, and it starts signed out instead of half signed in. Your sign-in and its device id stay on the device they belong to.
- A widget set to a project or custom list of an account you signed out of says to choose another list instead of showing a list of the new account with the same number.
- Widget contents and shares waiting to be added are left out of iCloud backups, and a share saved before signing out is not added to the next account's Inbox.
